# Personal Hub

A simple space to organize your space.

## Stack

Next.js (App Router, Cache Components) · React · TypeScript · Tailwind CSS v4 · shadcn/ui · Drizzle ORM · PostgreSQL · Zod · Biome

## Getting started

```bash
pnpm install
cp .env.example .env.local   # set DATABASE_URL
pnpm db:migrate
pnpm dev
```

## Scripts

`pnpm dev` · `pnpm build` · `pnpm lint` · `pnpm lint:fix` · `pnpm typecheck` · `pnpm db:generate` · `pnpm db:migrate` · `pnpm db:studio`
